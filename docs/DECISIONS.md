# Decisions

Choices made where the spec was silent or couldn't be followed literally. The spec's own decisions are in its section 14. Newest entries are added at the end of each table.

## Asked and confirmed (touch the stack, schema, or security)

| Topic | Decision | Why |
|---|---|---|
| Local S3 | RustFS (`rustfs/rustfs:1.0.4`) instead of MinIO | The `minio/minio` image is gone from Docker Hub. RustFS speaks the same S3 API, so the code is unchanged for R2. |
| Rate-limit storage | `rate_limit` table (`key`, `count`, `reset_at`) | OTP sends per email and handle checks per IP need a counter shared by every serverless instance. Fixed windows reset themselves, so no cron. |
| Snapshot contents | The full draft: all sections with their `visible` flag, plus image keys and resolved URLs | Discard and Restore rebuild the draft from a snapshot. Visible-only would delete hidden sections. The public page drops hidden sections on the server. |
| Image delivery | Public-read bucket, `users/*` only, served from the r2.dev URL | R2 custom domains need the zone on Cloudflare, but `profyle.io`'s nameservers are on Vercel. Keys are random UUIDs. |

## Implementation choices

| Topic | Decision |
|---|---|
| Next 16 middleware | `src/proxy.ts` (Next 16's name for middleware), only for hostname mapping. Auth checks live in pages. |
| Cache invalidation | `updateTag("site:{handle}")` from Server Actions (immediate expiry, read-your-own-writes). Also on onboarding claim. Non-live public results use a short `cacheLife` because holds expire by timestamp. |
| DB driver | `pg` + `drizzle-orm/node-postgres` everywhere. Pooled URL for the app, direct URL (`DATABASE_URL_UNPOOLED`) for migrations. |
| Email | nodemailer over SMTP everywhere: Mailpit locally, Resend's SMTP relay in staging/prod. |
| Autosave | One debounced `saveDraft(DraftDoc)` action with client-generated UUIDs, ownership-checked; positions come from array order. |
| Unpushed race | Profile row `FOR UPDATE` plus `clock_timestamp()` in save, push, discard, and restore. |
| Handle races | `pg_advisory_xact_lock(hashtext(handle))`, with the unique constraint as the final arbiter. |
| Held handle in the check API | Returns `taken`; the subdomain page says "isn't available". |
| Switch back | An undo: restore the previous handle, clear `previous_handle`, release the abandoned handle immediately, keep the cooldown. |
| Avatar crop | Center crop to 400×400; no crop UI. |
| Upload transport | Presigned PUT (R2 has no presigned POST) with signed Content-Type and Content-Length; the raw upload is deleted once converted to webp. |
| OTP "attempts left" | Counted on the client per code; the server enforces 5. |
| Version "View" | A page at `/editor/versions/[id]` rather than an in-drawer render. |
| Public route timing | A minimal public route ships with F8 so F8/F9 can be checked; F13 completes it. |
| Account deletion order | DB first (cascade releases the handle immediately), then a best-effort storage delete with orphans logged. |
| Accent and icons | One blue accent (`primary` for the primary action, `link` for links). Lucide for UI icons; inline SVGs for brand marks. |
| Dark mode | Tailwind `dark:` is a `prefers-color-scheme` media query; no toggle, no next-themes. |
| Git flow | Feature branches → PR to `staging` → fast-forward `main`. |
| PR previews | Email OTP only; OAuth callbacks can't match random preview URLs. |
| CI services | The same `docker-compose.yml` as local development, not Actions service containers. |
| Migrations on deploy | Vercel build runs `drizzle-kit migrate` only for production and the `staging` branch; other previews share the staging DB and skip it. |
| TypeScript | 5.9 as scaffolded. TS 7 is out, but typescript-eslint supports only < 6.1. |
| Better Auth schema | Generated by `pnpm auth:generate` from `better-auth.cli.ts`, because the CLI can't load a config that imports `server-only`. Its timestamps stay `timestamp` (no time zone) as generated; the spec says not to edit those tables. |
| Better Auth user IDs | Better Auth's default text IDs (`profile.user_id` is `text` per the spec); every Profyle table uses UUIDs. |
| DB backstops | CHECK constraints mirror the Zod rules (handle format, lengths, URL schemes, month-precision dates, end ≥ start, live requires a version). |
| Local Postgres port | Host port 5433, because a system Postgres already holds 5432 on the dev machine. |
| pnpm build scripts | `allowBuilds: false` for esbuild, sharp, and unrs-resolver; all three ship prebuilt binaries. |
| Class merging | shadcn's `cn` package (from `shadcn-ui/cn`), as generated by shadcn 4.23. |
| E2E data | E2E specs run against whatever DB the app server uses, with unique handles and emails per run. |
